# 1.0.218 交付方案贯穿展示

## 行为

交付列表、集群详情、单次交付详情、配置来源页和变更历史展示部署方案。支持搜索系列名称和结构。应用节点数不包含协调存储与入口等依赖的额外机器。

新生成交付保存 scheme 快照（方案ID、名称、真实角色台数、机制和能力限制），同时写入结构化计划、锁文件及离线环境准备手册。交付审查文档读取相同快照。待执行目标不覆盖集群当前已确认状态。

历史交付仅从已保存的 plan.json 的 scheme/contract 获取；依赖排在前面不能冒充主应用，同组件多个实例且无法确认主实例时不猜。无记录显示“方案未记录”，不从当前目录或机器数量反推历史能力。

部署填表和交付审查 AI skill 同步补充方案、节点、历史快照、当前/目标区分规范。
