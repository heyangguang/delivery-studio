# 公共参数与规则（1.0.222-dev）

## 可维护入口
组件 → 平台公共流程 → 参数与规则。表单和AI都可新增string/int/bool/enum参数、默认值、枚举项、整数范围；条件规则支持字段等值要求、隐藏并设置兼容值、冲突提示。
定义保存为manifest/host-parameters.yaml。平台统一驱动创建表单、后端校验和mw_hosts[机器].params传参，不使用任意脚本执行规则。业务任务需显式读取参数；AI可同时提交定义和公共任务代码。

## 首个实例
storage_mode=dedicated_disk保留原挂载要求。system_directory禁止disk/partition/initialize，预检检查路径类型和data_min_free_mb，准备/data普通目录、不执行磁盘脚本；Redis/PG/Patroni安装读取同一模式。
保持默认独立数据盘。创建交付后默认值被写入规范化规格，未来修改默认值不会覆盖已保存值。草稿不发布不生效；未知参数、错误类型、范围越界和冲突值均被后端拒绝。
