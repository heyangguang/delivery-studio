# 自动执行与交付报告验收记录：1.0.242

验收日期：2026-11-11。线上版本：1.0.242-dev。

## 已交付的功能

- 组件修订可以声明“自动执行、离线部署、仅出配置”，允许同时支持多种方式。发布时由后端校验；自动执行步骤缺少超时、后置条件或完成判据时拒绝发布，并保留草稿。
- “设置 → 执行节点”提供注册、限定集群/控制机器/目标机器、下载配置与运行程序、停用和安装说明。
- “交付 → 现场执行”可以选择节点和具体步骤，审核固定修订后授权执行，查看近期输出及下载日志，在步骤边界暂停、恢复或结束批次。
- 每次执行保存固定快照、步骤尝试、发起人、节点、起止时间、退出码、逐机汇总和日志。只有运行结果及完成检查都符合要求，才显示验证通过。
- 同一集群或机器的自动修改互斥。执行期间不能替换该交付、同步组件或篡改结果；生成替代修订期间也不能启动旧交付。
- 节点保存待回传事件及日志游标，断线后补传并去重。超时或节点异常退出不会自动重试；状态不明时保留锁，核实后才能解除。
- 报告默认显示结果摘要，明确区分执行节点验证、上传日志和人工填写。详细版包含批次、尝试、机器、退出码、逐机汇总、脱敏日志与完整日志入口；网页和 Word 导出共用筛选方式。
- 配置交付独立生成 configuration.zip，无需安装运行环境。页面显示“配置已生成”，不提供部署完成确认，也不能用它作为升级/扩容的已部署基线。
- 应用内组件编写、表单填写、交付复核、排错、文档编写技能已更新，增加 automatic-execution 技能。AI 可读取授权交付的执行批次和日志；现场执行仍需用户选择范围并确认。

## 使用边界

自动执行节点当前安装在交付的控制机器上；交付包、离线运行环境、SSH 信任和证书先按手册准备。现有 PostgreSQL/Redis 组件没有被批量改成自动执行：作者需要补齐真实的完成检查，验证并发布新修订后才能开放相应步骤。

本次没有在客户机器执行数据库安装、切主、恢复或磁盘操作。真实 PG/Redis 多机部署、网络分区及故障恢复仍需要专用测试环境验收。不能把本机临时任务通过等同于数据库全场景验收通过。

定时任务、独立于控制机器的执行节点、云 ELB 连接器、自动补偿和自动回滚不在本次开放范围。人工配置的入口仍由现场确认，不会自动标记为成功。
