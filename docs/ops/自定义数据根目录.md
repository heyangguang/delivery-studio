# 自定义挂载点与配置驱动表单

版本：1.0.235-dev。

机器表单的“挂载点 / 数据根目录”来自平台公共流程 manifest/host-parameters.yaml 的 data_root 定义，默认 /data。独立数据盘将其作为挂载点，系统盘模式将其作为普通目录；值保存在 hosts[].params.data_root。历史规格缺少该字段时按 /data 处理。

维护者入口：组件 → 平台公共流程 → 参数与规则 → 添加公共参数。支持文本、目录路径、整数、开关、选项；新增定义并发布后，创建交付表单自动生成控件，后端执行类型/默认值/规则校验，生成任务得到同一份参数。组件私有输入在对应组件“参数”中维护。定义字段不会自动实现业务逻辑：公共任务或组件任务须引用参数，AI可跨工作台提案并联合检查。

PG、Patroni 使用每台机器的 data_root 派生数据、备份和测试目录。Redis、etcd 的 data_dir 保持 /data 前缀的兼容配置，执行时将此前缀映射到目标机器的数据根目录；参数帮助已说明。不同机器可配置不同根目录，运维说明遇到多个根目录会提示按目标机器路径替换示例。

校验：规范绝对路径，禁止系统关键路径；预检拒绝符号链接路径，检查最近存在父目录的可用空间；磁盘脚本在处理设备之前验证路径。已有机器不能通过普通变更迁移数据目录。

验证：目录类型和生成测试、PG三种方案/Redis两种方案/etcd三种方案的 Ansible 语法检查；本机仅执行模板解析和断言验证自定义路径。通过隔离服务新增并发布一个全新公共文本参数，浏览器确认输入框自动出现；1440/768/390宽度验证。未在生产机器上格式化磁盘或迁移数据库。
