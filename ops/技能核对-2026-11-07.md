# 内置技能核对记录

范围：ai_skills 下全部 16 项，并核对 formSystem、controllerFacts、组件工具、交付文件提案工具。以当前仓库代码/模板为准，不把通用运维经验当作现场配置。

| 技能 | 核对和处理 |
| --- | --- |
| ansible-debug | 删除直接替换 SSH 指纹、inventory 写提权密码和无条件 diff 建议；保留离线入口约束 |
| component-authoring | 搜索定位代替通读；明确公共参数及草稿发布边界 |
| delivery-review | 控制节点和运行单点区分；多数派以方案为准 |
| deployment-form | 不猜设备/CIDR；证书工具与上传流程一致；保留切换组件及公共参数规则 |
| document-writing | 区分发布生成执行；运行入口和历史方案一致 |
| etcd-ops | 不假设 localhost、TLS、工具存在；压缩成员恢复不当只读检查 |
| haproxy-keepalived | 删除不存在的默认 admin.sock；纠正失败扣分和优先级关系 |
| incident-report | 不编造负责人和期限 |
| linux-diagnostics | 不硬编码统一时钟阈值；普通目录模式不误判未挂载 |
| offline-packages | 实际 trusted=yes/gpgcheck=0 不泛化成关闭安全校验建议 |
| postgresql-patroni | 分 single/replication/patroni；检查真正加载配置；bootstrap 与动态配置区分 |
| proposal-writing | 完整最小改动可跨文件；采纳更新包不等于现场执行 |
| reading-attachments | 截断覆盖范围、证书工具、草稿与执行状态 |
| security-triage | 库中无包不等于厂商未修复；运行环境影响不可一概排除目标机 |
| spreadsheet-analysis | 保存的端口声明不等于实时扫描；不把截断数据当全表；授权填表可用工具 |
| step-troubleshooting | 移除机械工具次数限制；新标签页组件建议说明 |

核对依据：runtime_assemble.go、ai_form.go、comp_ai.go、ai_patch.go、ai_kb.go、mwpack/platform/roles/mw_offline_repo、catalog/patroni、catalog/postgresql、catalog/haproxy、catalog/keepalived、frontend/src/aichat.tsx。

本轮仅更新内置规则，不覆盖用户个人技能、知识库和组件草稿；现场版本及自定义配置仍须在具体会话中读取核对。回归测试不能保证模型永远不偏离指令。
